## Acceptance Criteria (Gherkin-стиль)

**Scenario:** Поиск бренда по названию

**Given** пользователь находится на странице «Бренды»
**When** пользователь вводит текст в поле поиска (мин. 1 символ)
**Then** система отправляет GET-запрос к `/api/brands?search={text}`
**And** ответ должен быть в формате JSON

**Scenario:** Найденные бренды
**Given** система получила ответ от сервера
**When** список брендов не пуст
**Then** отображаются карточки с названием и логотипом каждого бренда
**And** время ответа не превышает 2 секунд

**Scenario:** Бренды не найдены
**Given** система получила ответ от сервера
**When** список брендов пуст
**Then** отображается сообщение «Ничего не найдено»

**Scenario:** Регистронезависимый поиск
**Given** пользователь вводит текст в поле поиска
**When** поисковый запрос содержит заглавные или строчные буквы
**Then** система игнорирует регистр и возвращает соответствующие бренды
