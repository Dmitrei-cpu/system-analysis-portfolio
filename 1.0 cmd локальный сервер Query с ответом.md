cmd локальный сервер Query с ответом
curl -X QUERY "http://localhost:5000/search" -H "Content-Type: application/json" -d "{\"filter\":{\"color\":\"white\"},\"limit\":20}"
Ответ:
{
  "method": "QUERY",
  "received": {
    "filter": {
      "color": "white"
    },
    "limit": 20
  },
  "status": "ok"
}
