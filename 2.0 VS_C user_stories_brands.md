# User Stories для маркетплейса (категория «Одежда»)

## Формат: «Я как [роль] хочу [действие] чтобы [цель]»

| # | User Story | Acceptance Criteria (Критерии приемки) |
|---|------------|----------------------------------------|
| US-1 | Я как **пользователь** хочу **просматривать список всех брендов** чтобы **выбрать интересующий меня бренд для покупки** | 1. На странице отображаются все бренды с названиями и логотипами.<br>2. Список загружается не более чем за 2 секунды. |
| US-2 | Я как **пользователь** хочу **искать бренд по названию** чтобы **быстро найти нужный бренд без прокрутки всего списка** | 1. В поле поиска можно ввести текст.<br>2. Поиск работает по частичному совпадению.<br>3. При отсутствии результатов показывается сообщение «Ничего не найдено». |
| US-3 | Я как **пользователь** хочу **сортировать бренды в алфавитном порядке** чтобы **легко ориентироваться в длинном списке** | 1. Нажатие на кнопку сортировки меняет порядок (А→Я или Я→А).<br>2. Список обновляется мгновенно. |
| US-4 | Я как **пользователь** хочу **перейти к товарам выбранного бренда** чтобы **посмотреть ассортимент и сделать покупку** | 1. Клик по карточке бренда открывает страницу с товарами.<br>2. На странице отображаются товары и баннеры бренда.<br>3. Если товаров нет, показывается сообщение «Нет товаров». |
| US-5 | Я как **контент-менеджер** хочу **создавать новые бренды** чтобы **добавлять новых производителей на маркетплейс** | 1. Можно ввести название, загрузить логотип, привязать коллекцию товаров.<br>2. Название должно быть уникальным.<br>3. После сохранения бренд появляется в списке. |
| US-6 | Я как **контент-менеджер** хочу **изменять существующие бренды** чтобы **обновлять информацию о производителях** | 1. Можно редактировать название, логотип, коллекцию.<br>2. Новое название не должно конфликтовать с другими брендами.<br>3. Изменения сохраняются мгновенно. |
| US-7 | Я как **контент-менеджер** хочу **удалять бренды** чтобы **убирать неактуальных производителей** | 1. Удаление требует подтверждения.<br>2. После удаления бренд исчезает из списка.<br>3. Товары бренда остаются в системе (без привязки). |
