# 📁 Портфолио системного аналитика | Дмитрий Чебыкин

Привет! Я — системный аналитик, стремящийся к уровню **Middle+**. Это мой публичный репозиторий, демонстрирующий мои практические навыки и глубокие теоретические знания в области системного анализа, проектирования API и моделирования процессов.

## 🎯 Моя цель

Ищу возможность стажировки или позиции Junior+/Middle системного аналитика, чтобы применять и развивать свои навыки в коммерческой разработке. Имею прочную теоретическую базу и стремлюсь к работе с архитектурно-значимыми задачами.

## 🛠️ Ключевые компетенции

*   **Работа с требованиями:** Выявление, анализ, спецификация (SRS), декомпозиция и трассировка.
*   **Моделирование:** Создание диаграмм в нотациях BPMN, UML (Use Case, Activity, Sequence).
*   **Проектирование API:** Опыт работы с REST API, OpenAPI (Swagger), JSON-RPC, а также теория gRPC и GraphQL.
*   **Проектирование БД:** Основы реляционных (SQL, нормализация) и NoSQL (Redis, Mongo) баз данных.
*   **Инструменты:** PlantUML, Draw.io, Git/GitHub, VS Code, Postman.

## 🎓 Образование и самообразование

*   **Профессиональная переподготовка:** Аналитик данных (ФГБОУ ДПО ИРПО, 2025)
*   **Текущее обучение:** Курс "Системный анализ" (Middle+/Senior) — углубленное изучение архитектурно-значимых требований, проектирования API и системной архитектуры.
