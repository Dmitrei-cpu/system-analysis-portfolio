# Use Case Specification (вертикальные таблицы)
  
## Use Case 1: Поиск бренда по названию
  
| Поле | Значение |
|------|----------|
| **Название Use Case** | U.C.1. Поиск бренда по названию |
| **Акторы** | Пользователь |
| **Предусловия** | Успешно выполнены сценарии перехода на страницу брендов |
| **Основной сценарий** | 1. Система отображает бренды списком.<br>2. Пользователь переходит к поиску бренда по названию.<br>3. Система отображает окно поиска бренда по названию.<br>4. Пользователь вводит название бренда.<br>5. Система отображает бренд(ы) по названию. |
| **Альтернативный сценарий** | |
| **Исключение** | 5.1. Система не нашла подходящий по названию бренд.<br>5.2. Пользователь видит, что бренда с таким названием не существует. |
| **Результат** | Бренд успешно найден |

## Use Case 5: Создание бренда (контент-менеджер)
  
| Поле | Значение |
|------|----------|
| **Название Use Case** | U.C.5. Создание бренда |
| **Акторы** | Контент-менеджер |
| **Предусловия** | Менеджер авторизован и имеет права на управление брендами |
| **Основной сценарий** | 1. Менеджер открывает форму создания бренда.<br>2. Вводит уникальное название, загружает логотип.<br>3. Выбирает коллекцию товаров.<br>4. Подтверждает создание.<br>5. Система сохраняет бренд и привязывает коллекцию.<br>6. Отображается сообщение об успехе. |
| **Альтернативный сценарий** | |
| **Исключение** | 2.1. Название не уникально → ошибка.<br>2.2. Не загружен логотип → ошибка.<br>2.3. Не выбрана коллекция → ошибка. |
| **Результат** | Бренд успешно создан |

## Use Case 6: Изменение бренда (контент-менеджер)
  
| Поле | Значение |
|------|----------|
| **Название Use Case** | U.C.6. Изменение бренда |
| **Акторы** | Контент-менеджер |
| **Предусловия** | Бренд существует в системе |
| **Основной сценарий** | 1. Менеджер выбирает существующий бренд из списка.<br>2. Открывает форму редактирования.<br>3. Изменяет название (уникальное, кроме себя), логотип, коллекцию товаров.<br>4. Подтверждает изменения.<br>5. Система сохраняет обновлённые данные.<br>6. Отображается сообщение об успехе. |
| **Альтернативный сценарий** | |
| **Исключение** | 3.1. При попытке изменить название на уже существующее (другой бренд) → ошибка.<br>3.2. При удалении логотипа без загрузки нового → ошибка. |
| **Результат** | Бренд успешно изменён |
  
---
  
## Use Case 7: Удаление бренда (контент-менеджер)
  
| Поле | Значение |
|------|----------|
| **Название Use Case** | U.C.7. Удаление бренда |
| **Акторы** | Контент-менеджер |
| **Предусловия** | Бренд существует в системе |
| **Основной сценарий** | 1. Менеджер выбирает бренд из списка.<br>2. Нажимает «Удалить».<br>3. Система запрашивает подтверждение.<br>4. Менеджер подтверждает удаление.<br>5. Система удаляет бренд и связи с коллекциями.<br>6. Отображается сообщение об успехе. |
| **Альтернативный сценарий** | |
| **Исключение** | 4.1. Пользователь отменяет удаление → удаление не выполняется.<br>4.2. Попытка удалить несуществующий бренд → сообщение «Бренд не найден». |
| **Результат** | Бренд успешно удалён |
