# Job Stories для маркетплейса (категория «Одежда»)

## Формат: «Когда [ситуация], я хочу [мотивация], чтобы [результат]»

| # | Job Story | Примечание |
|---|-----------|------------|
| JS-1 | **Когда** я захожу на страницу брендов, **я хочу** видеть все бренды в виде карточек, **чтобы** быстро оценить ассортимент. | Первое впечатление о магазине |
| JS-2 | **Когда** я знаю точное название бренда, **я хочу** ввести его в поиск, **чтобы** сразу перейти к его товарам без лишних кликов. | Ускоряет путь к покупке |
| JS-3 | **Когда** я вижу длинный список брендов, **я хочу** отсортировать его по алфавиту, **чтобы** легко найти нужный бренд. | Улучшает навигацию |
| JS-4 | **Когда** я выбираю бренд, **я хочу** увидеть все его товары и баннеры на одной странице, **чтобы** принять решение о покупке. | Концентрация внимания на бренде |
| JS-5 | **Когда** контент-менеджер получает нового производителя, **он хочет** создать бренд с названием и логотипом, **чтобы** быстро добавить его на площадку. | Автоматизация рутины |
| JS-6 | **Когда** меняется информация о бренде, **контент-менеджер хочет** отредактировать его данные, **чтобы** поддерживать актуальность каталога. | Поддержка качества данных |
| JS-7 | **Когда** бренд больше не сотрудничает с маркетплейсом, **контент-менеджер хочет** удалить его, **чтобы** не показывать неактуальную информацию. | Очистка каталога |
